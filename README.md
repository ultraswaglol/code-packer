#  Code Packer Tool

**Бесплатный онлайн-инструмент для безопасной и эффективной подготовки кода проекта к передаче в LLM (ChatGPT, Claude, Gemini).**

---

##  Перейти к инструменту

Начните паковать ваш код прямо сейчас:
**👉 [https://code-packer.ru/](https://code-packer.ru/) 👈**

---

##  Ключевые преимущества

1.  ** Client-Side Security (Максимальная безопасность):**
    *   Вся обработка файлов происходит **исключительно в вашем браузере** с помощью JavaScript.
    *   Ваш исходный код **НИКОГДА** не отправляется на сторонний сервер.
    *   Мы не храним и не просматриваем ваши файлы.

2.  ** LLM Context Optimization (Экономия токенов):**
    *   Автоматически игнорирует системные и "мусорные" папки (`.git`, `node_modules`, `venv`, `__pycache__`).
    *   Фильтрует бинарные файлы (картинки, видео, архивы), чтобы не тратить ценные токены.

3.  ** Чистая структура:**
    *   Генерирует наглядное дерево файлов, чтобы нейросеть лучше понимала архитектуру проекта перед анализом кода.

## 🛠 Как это работает?
Просто выберите корневую папку вашего проекта. Code Packer объединит содержимое всех релевантных файлов в один текстовый промпт, идеально отформатированный для моделей с большим контекстным окном (GPT, Claude Sonnet, Gemini Pro).

# Code Packer Tool (English)

**Free online tool for safely and efficiently preparing your code project for submission to LLMs (ChatGPT, Claude, Gemini).**

##  Go to the Tool

Start packing your code now:
**👉 [https://code-packer.ru/](https://code-packer.ru/) 👈**

##  Key Features

1.  ** Client-Side Security:**
    *   All file processing occurs **strictly in your browser** using JavaScript.
    *   Your source code is **NEVER** sent to any external server.
    *   We do not store or view your files.

2.  ** LLM Context Optimization (Token Saving):**
    *   Automatically ignores system and "junk" folders (`.git`, `node_modules`, `venv`, `__pycache__`).
    *   Filters out binary files (images, videos, archives) to save valuable LLM tokens.

3.  ** Clear Structure:**
    *   Generates a clear file tree structure so the AI can better understand the project architecture before code analysis.

##  How it Works?
Simply select your project's root folder. Code Packer combines the content of all relevant files into a single text prompt, perfectly formatted for large context window models (GPT-, Claude, Sonnet, Gemini).
